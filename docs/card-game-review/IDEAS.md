# Alternative mechanics and proposals
Author: strategy / Lead Game Designer. All entries below are PROPOSALS, not approved decisions. No empirical tests are claimed. Prior preparation is preserved at end and in revisions.

## v1.0 choices and rejected alternatives
- **40 rather than 60 cards; three reserve slots.** Reduces first-build card text, shuffling and board state. Keep 14 dedicated resources (35%) and 12 fighters. Risk: repeated card patterns and short draw clock; measure before expanding.
- **Guaranteed opening two resources/two fighters; bounded Supply.** Initial search prevents non-games and lets each player expose a planned class mix. Later Supply spends a non-resource hand card to fetch an actual resource from deck and consumes normal resource allowance. Rejected automatic external resource deck because the brief prioritizes resources inside the regular deck. Rejected unlimited resource conversion because it removes resource-card deckbuilding costs. Initial active choice is selected, not random; possible matchup advantage must be measured.
- **One ordinary currency for tactics and development.** Nodes use reusable resources with turn gates, one unlock/turn and four slots; fighter progress uses small achievement counters, never spendable development points. Rejected kill-funded research because aggression could turn an early lead into more progression. Rejected separate development income because it adds another per-turn track. Risk: saving for nodes might become obvious at certain resource counts; test actual missed-attack costs.
- **Common map/private ownership.** Both players have identical access and separate complete pools. Rejected one joint purchased tree: ownership, denial and first-player race would overshadow counter-building. Rejected random public market for first build: it adds availability variance to resource draws. Availability is public and never depleted by opponent.
- **Four paths retained but not four class silos.** Rage can buy Survival/RS or Aggression/RA; Hope has economy or burst damage; Luck gets offense or recovery by switching; Death gets progress recycling or card economy. No fifth class needed. Mixed M demands two real Stage II class investments, not merely a declared splash. Class bonuses remain after losing the qualifying fighter, avoiding cascading tree deactivation.
- **No respec/refund in v1.0.** Change direction with remaining slots; commitment is a cost, not an optimization puzzle. Rejected free respec because every turn could demand rebuilding markers and retroactively undoing upgrades/acquisitions. Rejected returning acquired cards on node loss because it requires searching hidden zones. Risk: a four-node full tree locks adaptation too soon. Measure how many games cap before a player understands opponent's plan; possible later alternative is five slots, NOT silently added to rules.
- **All-copy action upgrades, public replacement references.** Every Repair or Cycle uses its upgrade text without hidden markings or deck search. Rejected individually sleeved overlays: hidden identity leaks, double sleeving and reset burden. Rejected fighter-stat attachments alongside stages because it adds another health layer. Persistent S1 is the only global health modifier.
- **New cards enter hand and draw deck, not both directly into hand.** One copy gives immediate response; one shuffled copy changes future draws and deck composition. Earlier incremental r5 put second copy in discard: rejected in final text because this build has no discard-to-deck engine, making it mostly dead material. Each acquired name is two copies; no unlimited market and no main-deck access before unlock.
- **Evolution uses one stage and one capped progress counter per fighter.** No separate evolution cards to draw/search. Lethal removed before progress; no rescue by instant evolution. Rage requires opposing damage, Hope only actual tactical spending (not node/evolution), Luck positive attack damage without dice, Death real friendly losses with opponent points. Shared 2/3 thresholds ease handling but may NOT produce equal pacing.
- **Death sacrifice always gives opponent a point.** Reject disposable free tokens or sacrifice refunds. Conversion has a real reserve and scoreboard cost; DX/DE remove finite dead fighters rather than create repeat loss events. This is a deliberate recovery identity, not an invitation to suicide five fighters.
- **Counterplay without a response stack.** One defensive Reaction per attack; Main-targeted reserve pressure via Pursuit; temporary node tax via Disrupt. Rejected persistent node destruction/blanking: removing S1 health can cause surprise lethal and tracking cascades. Disrupt does not undo nodes or upgrades. Players can wait it out at a tempo cost.
